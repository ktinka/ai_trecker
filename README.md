# AI Trekker
### Что это вообще такое?
AI-Trekker - удобный инструмент для отслеживания положения человека в пространстве.
### Как оно работает?
В данном проекте есть две основные части:
1. логическая (загрузка данных, их обработка моделью и вывод результатов в удобном для человека формате)
2. физическая (корпус, плата и компоненты)

Работа трекера базируется на нескольких компонентах:
- arduino nano
- bluetooth module
- accelerometer
- accumulator

Используемая модель - логистическая регрессия
